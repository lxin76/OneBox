# 置顶文本 · OneBox 内置小工具

**一个常驻置顶的纯文本框：随手记、暂存与复用纯文本，一键复制/粘贴回目标软件。**

- 插件 id：`textpin`
- 数据目录：`data/plugin-state/textpin/`
- 源码：`src/OneBox.Plugins.TextPin/`（纯逻辑在 `src/OneBox.Plugins.TextPin.Core/`）
- 平台与接口说明见[平台 README](../../README.md)

## 功能

- **启动不弹窗**：宿主启动（或插件重启）时窗口**不会**自动出现，插件只在后台待命；按呼出热键或点托盘菜单才唤出，不打断你手上的工作
- **常驻置顶**：窗口默认浮在其他窗口最上方，唤出时出现在主屏中央（不遮挡任务栏），可拖动标题栏移动、拖动右下角缩放
- **不抢焦点**：默认带 `WS_EX_NOACTIVATE`，点击窗口不会打断你正在编辑的软件；点进文本框时会临时取得键盘焦点，离开后自动归还给原来的窗口
- **可编辑的纯文本框**：多行编辑、自动换行（可关）、字号可调
- **自动保存**：停止输入约 1 秒后落盘，失焦、隐藏与插件退出时再存一次
- **状态栏与宿主状态**：窗口底部实时显示字符数、行数、字节数与置顶状态；同一份摘要也会上报到工具箱里
- **显式复制/粘贴**：一键把文本复制到剪贴板，可选接着自动粘贴到前台窗口
- **读入剪贴板文本**：点击「读入」按钮或按热键，把剪贴板里的纯文本取进来（**只在这一次操作时读取，不监听剪贴板**）
- **抓取选中文字并置顶**：在任意编辑器里选中文字后按热键，自动模拟 Ctrl+C 复制并把文字置顶显示
- **长度上限保护**：超过上限的内容自动截断并提示，避免异常大的粘贴内容拖垮界面与磁盘写入

## 不监听剪贴板

这是本插件与「剪贴板历史」类工具最根本的区别：**插件不注册任何剪贴板监听器**。

- 系统里任何地方的复制动作都不会被感知，也不会被记录；
- 只有你点击「读入」按钮、或按下读入热键时，才会读一次当前剪贴板；
- 写入剪贴板同样只发生在你点击「复制」或按复制热键时。

### 「抓取选中文字」为什么也不算监听

按下抓取热键时，插件会：先记下当前剪贴板序号 → 模拟 `Ctrl+C` → 轮询剪贴板序号，
一旦**序号发生变化**就立刻取出文本，操作结束即停止。

- 用的是 `GetClipboardSequenceNumber` 轮询，**不是** `AddClipboardFormatListener` 监听器，没有常驻回调；
- 只有在序号真的变化时才认这次复制——所以不会把上一次留在剪贴板里的旧内容误当成"选中文字"；
- 整个等待最长约 1.2 秒，超时即放弃并提示，不会一直挂着；
- 抓到的是图片/文件等非文本内容时，会明确提示"选中的内容不是纯文本"。

## 全局热键（可在设置页自定义）

| 热键 | 功能 |
|---|---|
| `Ctrl+Alt+V` | 显示/隐藏文本框 |
| `Ctrl+Alt+P` | 把剪贴板里的纯文本读入文本框 |
| `Ctrl+Alt+C` | 复制文本框内容到剪贴板（不自动粘贴） |
| `Ctrl+Alt+X` | 抓取当前选中文字并置顶 |
| `Ctrl+Alt+K` | 修复键盘输入（重置卡住的修饰键），固定不可改 |

> 默认热键刻意避开 `Ctrl+Shift`——中文 Windows 上 `Ctrl+Shift` 会被输入法切换器拦截。
> 改键后由宿主重新注册；若组合键已被其他软件占用，会明确提示但保留你的设置。

## 窗口交互

| 操作 | 行为 |
|---|---|
| 拖动标题栏 | 移动窗口 |
| 拖动右下角 | 缩放窗口 |
| 点击标题栏 📌 | 切换置顶 |
| 点击 📥 | 把剪贴板文本读入（只在点击时读一次） |
| 点击 📋 | 复制全部文本（开启「复制后自动粘贴」时接着粘贴） |
| 点击 ⚙ | 打开设置窗口 |
| 点击 ✕ | 隐藏到托盘（热键或托盘菜单可再唤出） |
| 点击文本框 | 临时取得键盘焦点开始输入，离开后恢复「不抢焦点」 |
| 宿主启动时 | 窗口不出现，插件仅在后台待命；按呼出热键或点托盘菜单才显示 |
| 在别的软件里选中文字后按抓取热键 | 抓取并置顶该文字，窗口自动显示到最前 |
| `Ctrl+Enter` | 复制并粘贴到前台窗口 |
| `Esc` | 退出输入，恢复「不抢焦点」 |

> 抓取失败（没选中内容、目标程序不支持 Ctrl+C、选中的不是纯文本）只会在状态栏提示，**不会清空**窗口里已有的内容。

## 设置

设置窗口与宿主「设置中心」改的是同一份设置，互为同步。

| 设置 | 默认 | 说明 |
|---|---|---|
| 窗口置顶 | 开 | 始终保持在其他窗口上方 |
| 不抢焦点 | 开 | 点击窗口不打断当前软件 |
| 复制后自动粘贴 | 开 | 复制后自动模拟 `Ctrl+V` 粘贴到前台窗口 |
| 自动换行 | 开 | 关闭后长行改用横向滚动 |
| 字号 | 13 | 9–32 |
| 文本长度上限 | 200000 | 超出部分截断（可设 1000–5000000） |
| 开机自动启动 | 跟随宿主 | 只展示状态，注册/注销由宿主统一负责（插件内不处理） |
| 四个全局热键 | 见上表 | 在设置页用按钮录入，可看到「被占用」提示 |

设置页底部还有「打开数据目录」与「清空文本」。

## 实现要点

- **不监听剪贴板**：没有任何 `AddClipboardFormatListener`；`Services/ClipboardText.cs` 只提供一次性的读与写
- **抓取靠序号轮询**：`Services/SelectionCapture.cs` 用剪贴板序号变化判定"复制真的发生了"，避免旧内容冒充选中文字；等待期间才轮询，结束即停
- **抓取前归还前台**：若置顶窗正被激活（用户刚点过文本框），先把它占用的前台还给目标窗口，否则 Ctrl+C 复制的是置顶窗自己选中的内容
- **剪贴板写入串行化**：写入放后台专用 STA 线程的串行队列，UI 线程不会因剪贴板被其他程序占用而卡顿；写入失败重试后放弃并记日志
- **不抢焦点与输入的矛盾**：`WS_EX_NOACTIVATE` 会让窗口收不到键盘输入，因此鼠标按进正文区时临时 `AllowActivation(true)`，失焦后恢复 `WS_EX_NOACTIVATE` 并把前台交还给之前的窗口
- **防止回填触发保存**：`SetTextSilently` 用 `_suppressTextEvents` 抑制 `TextChanged`，否则启动加载与「读入」都会立刻触发一次保存与状态刷新
- **粘贴前等修饰键松开**：热键里若还按着 Alt，注入的 `Ctrl+V` 会变成别的组合，因此注入前先等 Ctrl/Alt/Shift/Win 全部松开
- **状态上报收敛到保存节流**：不是每敲一个字就发一条 IPC，而是随 1 秒的保存节流一起上报，避免把宿主日志与界面刷爆
- **设置边界校验**：宿主传来的 JSON 可能是任何东西，`SettingsSchema.Apply` 对每个键做类型与范围校验，非法值一律忽略并保留原值（有单测钉住）
- **纯逻辑可单测**：换行统一与截断（`PlainText`）、文本统计（`TextStats`）、落盘（`PinnedTextStore`）、设置声明（`SettingsSchema`）都在 `.Core` 里
