# 图标生成器

平台与各小工具的图标都由这里的脚本生成，改图标不用碰任何手工绘图工具。

## 用法

```powershell
# 需要 Python + Pillow
python tools/icons/gen_icons.py     # 生成并直接写回各项目的 Assets/
python tools/icons/preview.py       # 出检查图（放大看细节、像素级看小尺寸剪影）
```

`gen_icons.py` 会写出：

| 产物 | 位置 | 用途 |
| --- | --- | --- |
| `app.ico` | 各项目 `Assets/` | exe 图标（`ApplicationIcon`）+ 窗口图标（pack 资源） |
| `app.png` / `plugin-generic.png` | 宿主 `Assets/` | 界面列表图标（`BitmapImage` 解不了 `.ico`） |
| 母版 PNG/ICO | `master/` | 2048px 高分辨率母版与全套尺寸，供预览与追溯 |

> 生成器不依赖任何外部绘图工具：造型用 Pillow 在 2048 画布上几何绘制，
> 再逐尺寸降采样拿抗锯齿。这样参数全部可复现，也不需要在机器上装设计软件。

## 设计约定

各枚图标共用同一套「底」（squircle 深色渐变 + 内描边 + 角落辉光），**造型各不相同**，
保证缩到 16px 也能靠剪影区分：

| 图标 | 造型 | 语义 |
| --- | --- | --- |
| platform | 等轴测立方体 + 顶面插槽 | 宿主是承载各小工具的容器 |
| textpin | 文本卡片 + 右上角图钉 | 置顶文本；图钉表示"钉在最上层" |
| quicknote | 折角便签 + 镂空闪电 | 快速便签 |
| screenshot | 四角取景框 + 中心准星 | 截图 |
| recorder | 显示器轮廓 + 红色录制圆点 | 录屏 |
| generic | 芯片 | 未提供图标的第三方插件占位 |

## 小尺寸为什么要单独画

同一套造型要出 11 种尺寸（16/20/24/28/32/40/48/64/96/128/256）。
其中 16–28px **不是把大图缩小**，而是另走一条画法：

1. **笔画按目标像素反推加粗**——2048 缩到 16 是 128:1，不显式加粗的线在 16px 上不到半个像素，必然糊；
2. **去掉发光与渐变**，底板压成纯色，剪影才干净；
3. **按 alpha 包围盒把造型放大占满画幅**（小图标的通行做法）；
4. **改掉会糊在一起的细节**——例如截图在 16px 下不用圆环（会和框臂连成一朵花），改成方硬取景框 + 实心准星点。

`SMALL_SIZES` / `LARGE_SIZES` 控制分界，`Render.stroke()` 是加粗的唯一入口。

## 新增一枚图标

1. 写一个 `draw_xxx(r)`：用 `r.box()` / `r.pts()` 传 1024 基准坐标，用 `r.stroke(n)` 取线宽（自动处理小尺寸加粗）；
2. 在 `SPECS` 里登记底板渐变与辉光色；
3. 在 `DESTINATIONS` 里写上落地路径；
4. 需要 PNG 版本就加进 `PNG_DESTINATIONS`。

小尺寸下如果某个细节糊了，正确处理是在 `draw_xxx` 里按 `r.small` 分支换画法，而不是调大整体尺寸。
